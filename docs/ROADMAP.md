# SHAJ Retail Hub Roadmap

## V1 Foundation
- independent React application with SHAJ visual system
- shared Backend authentication
- business profile and application settings
- store/branch management
- POS registration and deactivate flow
- local POS health probe
- complete navigation/capability architecture

## V1 Operations
- canonical scoped configuration model
- effective configuration resolver
- branch/device overrides and revision history
- customer-safe sync/health telemetry
- users, roles and permissions management
- billing/inventory policy persistence
- receipt hardware mapping
- settings audit history

## V1 Offline Management
- POSService status, sync, backup and version endpoints
- configuration snapshot download and local SQLite cache
- configuration acknowledgement/revision tracking
- manual sync and recovery workflow
- device compatibility/version policy

## Later
- notifications center
- integrations registry
- payments and settlements control plane
- automation rules
- AI daily briefing, forecasting and exception intelligence
- omnichannel commerce
- developer API/webhook portal
- enterprise SSO and advanced compliance
